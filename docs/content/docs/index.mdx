<Callout title="Proof of concept" type="info">
    This is a small demo built quickly to show that Simulink and CARLA can co-simulate.
    It works for the blocks documented here, but it isn't a maintained or complete library.

    It is also limited to one combination of versions: MATLAB R2020a, Python 3.7.9 and CARLA 0.9.15.
    MATLAB only supports certain Python versions, and each CARLA release needs its own Python client,
    so other combinations may not work. A fuller implementation is meant to remove these limits.
</Callout>

This project aims to connect Carla and Simulink, showing how they can work together with some examples. This combination could make it easier to develop self-driving cars.
(_The following project is inspired by [MATLAB-Carla-Interface](https://github.com/darkscyla/MATLAB-Carla-Interface) by [@darkscyla](https://github.com/darkscyla)_).

## Requirements

---

To use this library the following software are needed:

-   [MATLAB](https://www.mathworks.com/products/matlab.html)
-   [Simulink](https://www.mathworks.com/products/simulink.html)
-   [Carla](https://carla.org)
-   [Python](https://www.python.org)

### Versions Compatibility

The following library was developed using:

-   Carla `v0.9.15`
-   Matlab `2020a`
-   Python `3.7.9`

<Callout title="Warning" type="warn">
    Make sure the installed versions are compatible. Other versions are untested.

    - MATLAB: [Versions of Python Compatible with MATLAB Products by
    Release](https://www.mathworks.com/support/requirements/python-compatibility.html)
    - Carla: [Carla Documentation](https://carla.readthedocs.io/en/latest/)

</Callout>

## Getting Started

---

<Steps>
    <Step>
        <h3>Get the library</h3>
        Clone or download [the repository](https://github.com/aalaeDev/carla-for-simulink). There is no packaged toolbox yet.
    </Step>
    <Step>
        <h3>Point it at CARLA</h3>
        In `config.json`, set `CarlaPath` to your CARLA install folder. The defaults are for a Windows build of CARLA 0.9.15.
    </Step>
    <Step>
        <h3>Run `launch.m`</h3>
        It adds the library to the MATLAB path, opens the example model (`examples/SpectatorFollowingVhcl.slx`), finds a free port and fills in the map and vehicle lists.
    </Step>
</Steps>
